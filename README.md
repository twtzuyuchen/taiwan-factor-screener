# 台股五因子選股器 Taiwan 5-Factor Stock Screener

單一 HTML 檔案、純瀏覽器端執行的因子選股工具。依據**價值 (Value)、質量 (Quality)、動能 (Momentum)、規模 (Size)、低波動 (Low Volatility)** 五大因子，對台股上市（TWSE）與上櫃（TPEx）股票計算 Z-Score 綜合評分並排名。

資料來源分成兩塊（這是修正過的架構，理由見下方「已知限制」）：

- **全市場快照**（流動性排序、本益比/股價淨值比）：證交所 [TWSE OpenAPI](https://openapi.twse.com.tw/) 與櫃買中心 [TPEx OpenAPI](https://www.tpex.org.tw/openapi/) — 免金鑰、免申請、無方案限制。
- **個股歷史數據**（股價走勢、財報、資產負債表、市值）：[FinMind API](https://finmindtrade.com/analysis/#/data/api) — 需要免費 token，逐檔查詢。

> ⚠️ 本工具僅供研究與教育用途，不構成投資建議。因子評分是橫斷面統計方法，不保證未來績效。

## 快速開始（GitHub Pages 部署）

1. Fork 或下載本專案到你自己的 GitHub 帳號。
2. 到 repo 的 **Settings → Pages**，Source 選擇 `main` branch、根目錄 `/`，儲存。
3. 等待 1–2 分鐘，GitHub 會給你一個網址，例如：
   `https://<你的帳號>.github.io/<repo名稱>/`
4. 打開該網址即可使用（`index.html` 就是整個程式，不需要任何後端）。

也可以完全不用 GitHub Pages，直接把 `index.html` 下載到本機，用瀏覽器打開就能跑。

## 使用前準備：申請 FinMind Token

1. 到 [FinMind 官網](https://finmindtrade.com/) 免費註冊帳號。
2. 登入後在會員頁面取得你的 API Token。
3. 打開本工具，貼在最上方「FinMind API Token」欄位。
   - 不貼 token 也能跑，但 FinMind 對匿名請求的額度非常低，抓不到幾檔就會被限速。
   - 註冊帳號後額度會提高；若需要抓更大的選股池（例如全市場 1700+ 檔），建議升級 FinMind 付費方案，否則會很慢或被限速中斷。

## 使用步驟

1. **設定 API**：貼上 token，選擇選股池大小（建議先從 100–150 檔開始測試，額度足夠再加大）、動能/波動回看天數、市場範圍。
2. 按 **「測試 API 連線」**：會抓幾筆樣本資料印在畫面上，確認欄位名稱正常（FinMind 資料集欄位偶爾會調整，如果對不上，程式頂端 `CONFIG` 物件可以直接修改欄位對應）。
3. 調整 **五個因子的權重滑桿**（預設平均權重 20% 各一）。
4. 按 **「開始抓取並計算因子分數」**。
   - 程式會先抓全市場股票清單與最新一日報價快照，依成交金額篩出流動性最高的前 N 檔作為選股池（避免抓完全市場 1700+ 檔導致 API 額度爆掉，也符合「可投資性」原則——流動性太差的股票即使因子分數高也不好真的買賣）。
   - 接著逐檔抓歷史股價、財報、資產負債表，計算動能、波動度、ROE、負債比、EPS 穩定度。這一步會花比較久（每檔股票有 request 間隔以避免觸發速率限制），可以在畫面下方看即時進度與 log。
   - 若抓到一半想停止，重新整理頁面即可；已抓過的資料會快取在瀏覽器 `localStorage`，下次執行同樣參數會直接讀快取、不用重抓（按「清除本機快取」可強制重抓最新資料）。
5. 完成後畫面會出現排名表格，可點欄名排序，也可以匯出 CSV。

## 五大因子計算方式

| 因子 | 資料來源 | 計算邏輯 | 方向 |
|---|---|---|---|
| 價值 Value | TWSE `BWIBBU_d` / TPEx `tpex_mainboard_peratio_analysis`（官方全市場快照，PER、PBR） | 對 PER、PBR 做 Z-Score 後取負號平均 | 越低越好 |
| 質量 Quality | FinMind EPS（`TaiwanStockFinancialStatements`，逐檔查）＋ 資產負債表（`TaiwanStockBalanceSheet`，逐檔查）＋ PBR 反推每股淨值 | ROE（近四季 EPS 加總／每股淨值）越高越好；負債比（負債／資產）越低越好；EPS 波動係數（近8季標準差／平均）越低越好 | 綜合 |
| 動能 Momentum | FinMind 歷史股價（`TaiwanStockPrice`，逐檔查） | 過去 N 個交易日累積報酬率（N 可調整，預設120） | 越高越好 |
| 規模 Size | FinMind `TaiwanStockMarketValue`（逐檔查；查不到則自動改用「收盤價 × 成交金額」流動性代理值，畫面會標示 ≈） | 市值 Z-Score 取負號 | 越小越好 |
| 低波動 Low Volatility | FinMind 歷史股價日報酬（逐檔查） | 年化標準差（√252 年化） | 越低越好 |

綜合分數 = 五個因子 Z-Score 依權重加權平均。權重滑桿總和不需要等於 100，程式會自動正規化。

## 已知限制 / 你可能要注意的事

- **為什麼要拆成兩個資料來源**：FinMind 免費方案不允許「省略 `data_id`、一次查整個市場」的請求（例如不指定股票、只給日期查全市場股價），呼叫這種端點在瀏覽器上常會直接顯示成 `Failed to fetch`，即使你已經貼上有效 token 也一樣，因為問題不是認證失敗，是這個查詢型態本身在免費方案就不開放。所以「全市場快照」（流動性排序、本益比/股價淨值比）改用證交所/櫃買中心官方 Open API（本來就設計成免金鑰的全市場單日快照）；「個股歷史數據」則維持用 FinMind，但一定帶著 `data_id` 逐檔查，這種用法免費方案是可以用的。
- **TWSE/TPEx 官方 API 沒有歷史查詢**：這兩組官方端點都只回傳「最新一個交易日」的快照，沒有指定日期回溯的參數。所以本工具的流動性排序、PER/PBR 一定是抓執行當下最新的收盤資料，不能拿來查過去某一天的排名。
- **CORS 風險**：官方開放資料平台通常設計給外部程式（含瀏覽器）直接呼叫，但我沒辦法在建置這個工具的環境裡實際連線測試 CORS 是否開放。如果按「測試連線」後 TWSE/TPEx 那幾項一直顯示「非陣列」或請求失敗，很可能是被瀏覽器的同源政策擋下，這時候需要一個小型代理伺服器（例如 Cloudflare Worker 轉發請求）繞過，或改回用有 CORS 支援的第三方資料服務。
- **規模因子的市值資料**：程式會先嘗試用 FinMind 的 `TaiwanStockMarketValue`（逐檔帶 `data_id` 查詢，免費方案應該可用）；如果那檔股票查不到，會退回用「收盤價 × 成交金額」當代理值（不是真的市值，只是流動性的粗略代理），表格中會用 `≈` 標示。
- **本益比/股價淨值比欄位名稱**：TWSE `BWIBBU_d` 與 TPEx `tpex_mainboard_peratio_analysis` 的實際 JSON 欄位名稱，我是依官方文件描述推斷、無法連線實測，`CONFIG` 裡針對每個欄位都列了好幾個候選名稱去嘗試比對，但仍可能對不上。用「測試連線」看實際回傳的原始欄位，對不上就直接改 `CONFIG.TWSE.FIELDS` / `CONFIG.TPEX.FIELDS`。
- **請求速率限制**：FinMind 對免費帳號仍有每小時請求數限制。選股池開太大（例如全市場 1700+ 檔 × 3 個資料集/檔）容易跑到一半被限速。建議善用內建的 localStorage 快取，分批、跨天執行；已經抓過的股票不會重抓。
- **動能因子波動大**：如同因子投資的原則，動能因子本身波動劇烈、反轉時容易「咬人」，不建議把動能權重拉到極端值單獨使用，建議搭配質量或低波動因子平滑風險。
- **這不是回測工具**：本工具只做「單一時點的橫斷面排名」，不驗證因子策略的歷史績效。若要驗證某個因子組合長期是否有效，需要另外做時間序列回測（可參考同開發者先前做的 TWSE/TPEx 回測工具）。
