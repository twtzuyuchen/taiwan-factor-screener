資料來源

這個頁面本身不呼叫任何外部 API，只讀取同一個 repo 裡預先算好的 data/factors_latest.json。 資料是由 GitHub Actions 排程在伺服器端執行 scripts/build_factors.py 產生的：全市場快照取自 TWSE / TPEx 官方 Open API（免金鑰），個股歷史數據取自 FinMind API。伺服器對伺服器的請求不受瀏覽器 CORS 限制，所以比純前端版本穩定。

價值 — 好貨不貴。用 PER、PBR 找出被低估的公司。
質量 — 買得放心。ROE 高、負債低、盈餘穩定的績優股。
動能 — 強者恆強。近期相對抗跌抗漲的股票。⚠️ 波動大，不建議單獨使用。
規模 — 船小好掉頭。小市值溢價，但純小型成長股風險高，建議搭配價值因子。
低波動 — 穩中求勝。長期複利效果通常優於大起大落的股票。
